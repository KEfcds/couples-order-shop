# 💗 心动点单小铺（couples-order-shop）

一个纯静态的「情侣点单小铺」网页：想一起吃什么、想让 TA 陪你做什么、想去哪里玩……
点一点下单，店主接单，还能实时推送到对方的手机。灵感来自抖音的「AI 自制情侣点单小铺」。

- ✅ **单文件网页**（`index.html`），无框架、无构建、无依赖，双击就能玩
- ✅ 店主名字、客人称呼、店名、标语、菜单、价格 **全部可以在页面设置里随时改**
- ✅ 三大菜单：🍜 吃什么 / 🎀 陪你做 / 🎡 去哪玩，用 💗 当货币
- ✅ 购物篮、备注、期望时间、订单小票、接单/婉拒/完成、收入统计
- ✅ 可选**双人实时同步**（免费、无需注册账号），两边手机实时互发订单和接单状态
- ✅ 可选**手机推送**：ntfy App / Bark(iOS) / Server酱(微信) / 自定义 Webhook
- ✅ 数据只存在本地浏览器，支持导出/导入配置

---

## 一、发布到你的 GitHub（3 步上线）

1. 新建一个仓库，比如 `couples-order-shop`（**公开**仓库才能免费用 GitHub Pages）。
2. 把本目录的 4 个文件传上去：`index.html`、`manifest.webmanifest`、`icon.svg`、`sw.js`（网页端直接 Upload files 即可）。
3. 打开仓库 **Settings → Pages**，Source 选 `Deploy from a branch`，分支选 `main` / 目录选 `/ (root)`，保存。

等 1~2 分钟，访问 `https://<你的用户名>.github.io/couples-order-shop/` 就能用了。
把这个链接发给对象，TA 手机浏览器打开后「添加到主屏幕」，就像装了个小 App。

> 本地玩：直接双击 `index.html` 也能下单（单机模式），双人同步建议上线后再用。

## 二、改店主名字（和其他一切）

- **页面里改**（推荐）：右上角 **⚙️ 店铺设置 → 店铺信息**，店名/店主名字/客人称呼/标语随意改，保存立即生效，永久记住。
- **链接参数改**：`https://xxx.github.io/couples-order-shop/?owner=小笨蛋&shop=思思念念小铺&customer=宝贝`
  （shop=店名 / owner=店主 / customer=客人 / tagline=标语，会自动保存）
- **改代码里的默认值**：`index.html` 搜 `DEFAULT_SETTINGS`，那里的店名、默认菜单、价格就是出厂设置。

## 三、双人玩法（推荐）

1. 两个人的手机都打开你的网页。
2. 各自点 **⚙️ → 双人实时同步 → 打开开关 → 「掷一个」生成房间码**。
3. 一人把房间码发给另一人，对方粘进同一个输入框保存（**两边房间码必须一样**）。
4. 完成！此后任何一边下单、接单、完成订单，另一边的页面实时刷新。

原理：通过免费公共消息服务 [ntfy](https://ntfy.sh) 的主题收发消息，不需要注册账号、不需要服务器。
房间码就是主题名，请像密码一样保管（拿到码的人就能看你们的订单）。

### 让手机在「网页没打开」时也收到推送

页面开着时，新订单会实时弹出来。如果希望网页没开也能收到系统通知：

| 方式 | 适合 | 怎么做 |
|---|---|---|
| **ntfy App**（推荐，安卓/iOS 都行） | 想免费用 | 手机装 ntfy App → 订阅主题填 `你的房间码-push`（注意有 `-push` 后缀） |
| **Bark** | iPhone | App Store 装 Bark → 复制 App 里的 Key → 粘到 ⚙️ 设置「手机推送」→ 发测试推送 |
| **Server酱** | 微信接收 | [sct.ftqq.com](https://sct.ftqq.com) 免费申请 SendKey → 粘到设置里 |
| **自定义 Webhook** | 进阶 | 填一个 `https://` 地址；含 `{message}` 占位符时按 GET 模板发送，否则 POST JSON |

配置好点「🔔 发送测试推送」验证。下单时会同时走所有已配置的渠道。

## 四、菜单和价格

设置里的「菜单管理」可以直接增删改每一项：图标、名字、描述、价格（0~999💗）。
三个分类对应三种心愿：吃什么 / 陪你做 / 去哪玩。改完点「保存设置」。

## 五、数据与隐私

- 订单和设置都存在**本机浏览器的 localStorage**，不会上传到任何服务器（推送消息除外）。
- 换手机/清浏览器数据前，先在设置里「📤 导出配置」；新手机「📥 导入配置」。
- 「清空订单」只影响本机记录。

## 六、常见问题

- **推送没收到？** 网页关着时浏览器提醒不可靠，建议装 ntfy App 订阅 `房间码-push`，或配置 Bark（走苹果系统通道，很可靠）。检查设置里「测试推送」是否成功。
- **同步收不到？** 确认两边房间码完全一致、开关都打开（订单看板顶部小圆点应为绿色）；ntfy.sh 在个别网络下可能较慢，可在设置里换自建/镜像 ntfy 服务器（需公网 https）。
- **Pages 打开 404？** 确认仓库名、分支、`/ (root)` 设置正确，等 1~2 分钟再刷新。
- **想自己部署到别的静态托管？** 任意支持静态文件的都行（Vercel / Netlify / 云开发静态托管…），无需任何配置。

## 七、文件说明

```
index.html            全部功能都在这一个文件里（样式 + 逻辑内联）
manifest.webmanifest  PWA 清单（添加到主屏幕用）
icon.svg              应用图标
sw.js                 离线缓存（可选，失效也不影响使用）
```

安全说明：页面里所有出站请求（ntfy / Bark / Server酱 / Webhook）都强制校验为公网 `http(s)` 地址，
自动拒绝 localhost、内网 IP 等目标；房间码建议使用「掷一个」生成的随机码。
